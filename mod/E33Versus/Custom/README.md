# Custom characters

Each folder here is one custom versus character, made by **CharForge** from a 3D model:

```
Custom/<id>/character.lua   name, base unit, cost (edit freely)
Custom/<id>/mesh.lua        the model, cut per bone of the base unit (generated)
Custom/<id>/*.png           textures and the portrait (generated)
```

Make one: drag a model (`.glb`, `.gltf`, `.fbx`, `.obj`, `.vrm`, `.dae`, `.blend`, `.usd`...) onto
`CharForge/CharForge.exe` (needs Blender 4.2+ installed), or see `CharForge/README.md` for the command line.
Delete a folder to remove that character. In game: **VERSUS** -> character select -> **Custom** tab.
